# Fundamental Acceleration 축

목적: 주가가 오른 뒤 따라가는 대신, 구조적 수요가 **수주·백로그 → 매출 → 마진·EPS → 가이던스**로 전환되는 기업을 조기에 찾는다.

## 점수 구조

| 하위축 | 가중치 | 검증 지표 |
|---|---:|---|
| 수요 가시성 | 35% | backlog 성장률, book-to-bill, orders 성장률 |
| 매출 성장 | 25% | 최근 분기 YoY 매출 성장률 |
| 영업 레버리지 | 25% | 마진 개선 bps, 이익성장률-매출성장률 스프레드 |
| 가이던스 | 15% | 상향 100, 강한 신규 가이던스 80, 유지 50, 하향 0 |

원자료가 없는 지표는 임의 추정하지 않고 null로 둔다. 사용 가능한 하위축만 재가중하며 coverage를 함께 표시한다. 따라서 점수만 비교하지 않고 coverage와 원자료를 같이 본다.

## 정규화 구간

- backlog 성장: 0~80% → 0~100점
- book-to-bill: 1.0~1.5x → 0~100점
- orders 성장: 0~100% → 0~100점
- 매출 성장: 10~100% → 0~100점
- 마진 개선: 0~1000bp → 0~100점
- 이익성장률-매출성장률: 0~100%p → 0~100점

이 구간은 절대 기업가치 평가가 아니라 **가속 여부를 탐지하는 스크리닝** 용도다. 밸류에이션, EPS revision, 주가-EPS 괴리, 포트폴리오 중복은 기존 투자매력도/비중조절 로직에서 별도로 본다.

## 라벨

- 80 이상: 가속 강함
- 65~79: 가속
- 50~64: 확인
- 50 미만: 관찰

## 운영 파일

- `fundamental-acceleration-source.json`: 공시·실적발표 기반 원자료와 출처
- `scripts/build-fundamental-acceleration.mjs`: 재현 가능한 점수 계산
- `fundamental-acceleration.json`: 최신 후보 순위와 하위축 점수

## 현재 후보군 (2026-09-12)

LITE, DELL, CRDO, VRT, DY, CLS, COHR를 우선 트래킹한다. 이는 매수 추천 목록이 아니라 Fundamental Acceleration 후보군이다. 실제 매수 우선순위는 기존 보유비중, 동일 수요처 노출, 밸류에이션, EPS revision, 가격 조건, 매크로 게이트를 추가 반영한다.

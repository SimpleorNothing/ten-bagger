# 투자매력도 V4 산출 기준

적용 화면: 비중조절 결정판의 추정 리비전 트래커  
현재 모델: `investment-scores-v4` / `4.0.0`

## 1. 점수 구조

```text
V4 최종 투자매력도 = 외생 데이터 점수 + 내부 판단 보정
```

- 외생 데이터 점수: 검증된 시장·실적 데이터만 사용한다.
- 내부 판단 보정: γ와 사이클 단계의 영향을 별도 표시한다.
- 실제 비중조절: 보유비중·집중도·중복 노출·매크로 게이트를 별도 로직에서 반영한다.
- V3 점수도 `scores.json`에 함께 저장하지만 화면에는 V4를 표시한다.
- 산출 대상은 04 알파 찾기 Value Chain의 전체 상장 종목·ETF다. 원자료가 없는 대상도 목록과 `scores.json`에서 누락하지 않고 `자료부족`으로 표시한다.

## 2. 외생 데이터 점수

| 축 | 가중치 | 구성 |
|---|---:|---|
| 단기·중기 리비전 모멘텀 | 35% | Q1 30일 30%·Q1 90일 15%·FY+1 30일 35%·FY+1 90일 20% |
| EPS 성장 | 20% | FY+1 EPS 증가율의 Nasdaq-100 순위 백분위 |
| 실제 밸류에이션 | 20% | Forward P/E 역백분위 60%·GARP 백분위 40% |
| 컨센서스 폭 | 10% | EPS 상향비율 60%·애널리스트 평점 역백분위 40% |
| 가격−EPS 괴리 | 15% | 주가 30일 상승률과 FY+1 EPS 30일 리비전의 차이 |

유효한 축만 재가중한다. 원자료 기준 전체 커버리지가 55% 미만이면 점수를 표시하지 않는다. 커버리지는 점수를 두 번 감점하는 용도가 아니라 산출 가능 여부와 신뢰도를 표시하는 값이다.

## 3. 순위 백분위

비교 모집단은 Nasdaq 공식 Nasdaq-100 구성 증권이다. EPS·Forward P/E·평점 원자료는 Yahoo Finance `quoteSummary`를 사용한다.

```text
순위 백분위 = 모집단 내 실제 값의 중간순위 ÷ (유효표본수-1) × 100
```

- 최저값 0점, 최고값 100점
- 동률은 중간순위를 사용
- 중앙값은 약 50점
- 종목이 Nasdaq-100 밖에 있어도 같은 분포에 값을 삽입해 상대 위치를 계산
- P10·P50·P90은 화면과 감사용이며 점수 선형보간의 앵커로 사용하지 않음
- 유효표본 50개 미만이면 벤치마크 생성 실패

상대점수만으로 시장 전체 악화를 숨기지 않도록 FY+1 EPS 30일 리비전의 절대 상태를 `상향·보합·하향`으로 함께 저장한다.

## 4. 가격−EPS 괴리

```text
괴리 = 주가 30일 상승률 - FY+1 EPS 30일 리비전

괴리 ≤ 0%p       → 100점
괴리 0~30%p      → 100점에서 0점까지 연속 감소
괴리 ≥ 30%p      → 0점
```

기존의 추가 감점 방식은 제거했다. 같은 EPS 악화를 리비전·컨센서스·감점에서 다시 차감하지 않는다.

## 5. 내부 판단 보정

내부 판단은 외생 데이터 점수 안에 섞지 않고 최종 단계에서 별도 표시한다.

| 상태 | 보정 |
|---|---:|
| γ open / flagged / spent | +2 / -2 / -6 |
| 사이클 태동 / 초입 / 가속 / 성숙 / 과열 | 0 / +2 / +1 / -2 / -5 |

초입과 가속은 기대수익과 실적 확신의 차이를 반영해 모두 플러스지만 초입을 더 높게 둔다. 이 보정은 내부 판단이므로 화면 툴팁과 `scores.json`에서 데이터 점수와 분리한다.

## 6. 제거한 중복·불연속 규칙

V4에서는 다음 V3 감점을 사용하지 않는다.

- Q1 EPS 30일 하향 추가 감점
- FY+1 EPS 30일 하향 추가 감점
- 하향 애널리스트 우세 추가 감점
- 과열 8점 추가 감점
- 상승여력 60% 초과·목표가 리비전 0% 이하 절벽 감점

EPS 하향은 리비전 순위와 컨센서스 폭에서 반영되고, 과열은 내부 판단 보정에서 한 번만 반영된다.

## 7. 라벨

| 라벨 | 기준 |
|---|---|
| 최우선 | 80점 이상이며 FY+1 EPS 30일 상향, Q1 EPS 30일 비하향 |
| 우선 | 68점 이상이며 FY+1 EPS 30일 상향 |
| 중립 | 55점 이상 |
| 관찰 | 45점 이상 |
| 후순위 | 45점 미만 |
| 자료부족 | 커버리지 55% 미만 |

상대순위가 높더라도 절대 EPS가 하향이면 `최우선·우선`으로 승격하지 않는다.

## 8. 재현성과 감사

| 파일 | 역할 |
|---|---|
| `revision-benchmark.json` | Nasdaq-100 분포·P10/P50/P90·정렬값·종목별 순위 |
| `scores.json` | 종목별 V3·V4·차이·입력값·하위축·보정·커버리지 |
| `gamma.json` | 개별 종목 검증 원자료와 γ·사이클 상태 |
| `scripts/fetch-revision-benchmark.mjs` | 벤치마크 생성 |
| `scripts/build-investment-scores.mjs` | V3·V4 서버 계산과 스냅샷 생성 |
| `scripts/apply_zero_base_investment_score.py` | 저장된 점수를 화면에 표시 |
| `scripts/test-value-chain-score-coverage.mjs` | Value Chain 전체 티커의 gamma·scores 포함 여부 회귀검사 |

클라이언트는 점수를 다시 계산하지 않는다. `scores.json` 또는 벤치마크가 없거나 스키마가 다르면 `산출 실패`를 명시한다.

## 9. 변경 관리

- 모델·가중치·라벨 변경은 코드, 본 문서, `OPS.md`, 변경 이력을 같은 PR에서 수정한다.
- PR에는 V3와 V4의 전 종목 점수·순위 차이를 첨부한다.
- 점수 변화 원인을 원자료·벤치마크·모델 변경으로 구분한다.
- 임의 임계값을 추가할 경우 근거·역할·한계·재검토 시점을 명시한다.
- 과거 특정 날짜의 점수와 백분위를 본문에 하드코딩하지 않는다. 실제 값은 해당 날짜의 `scores.json`과 `revision-benchmark.json`으로 재현한다.

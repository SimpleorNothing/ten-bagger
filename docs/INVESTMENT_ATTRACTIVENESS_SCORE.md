# 투자매력도 점수 산출 기준

기준 버전: `revision-benchmark-v1`  
적용 화면: 05 리밸런싱 · 추정 리비전 트래커  
목적: 현재 포트폴리오 비중을 제외하고, 오늘 전량 현금이라는 가정에서 종목의 상대 투자매력도를 0~100점으로 비교한다.

## 1. 점수의 성격

- 투자매력도는 제로베이스 종목 점수다. 실제 비중조절 우선순위와 다르다.
- 현재 보유비중, 산업 집중도, ETF 중복 노출과 매크로 매수 게이트는 실제 비중조절 단계에서 별도로 반영한다.
- 점수는 수익률 예측값이 아니라 EPS 리비전, 성장, 밸류에이션, 촉매와 컨센서스를 동일 규칙으로 비교한 상대평가값이다.
- 원자료가 부족해 유효 데이터 가중치가 55% 미만이면 점수를 표시하지 않는다.

## 2. 최종 산식

```text
가중 기초점수
= (3개월×30 + 6개월×25 + 밸류×20 + 촉매×15 + 컨센서스×10)
  ÷ 유효 데이터 가중치

최종점수
= round(clamp(가중 기초점수 - 리스크 감점, 0, 100))
```

자료가 없는 하위 항목은 임의 보정하거나 직전 값을 유지하지 않는다. 해당 가중치를 제외하고 유효한 항목만 재가중하며, 전체 데이터 커버리지를 함께 표시한다.

## 3. EPS 리비전 점수의 실증 기준

### 3-1. 비교 모집단과 출처

| 항목 | 기준 |
|---|---|
| 모집단 | Nasdaq-100 공식 구성 증권 전체 |
| 구성종목 출처 | Nasdaq 공식 `list-type/nasdaq100` API |
| EPS 원자료 | Yahoo Finance `quoteSummary.earningsTrend` |
| 갱신 주기 | 주가·리비전 자동 갱신 워크플로 실행 시마다 |
| 최소 유효 표본 | 지표별 50개 |
| 저장 파일 | `revision-benchmark.json` |

Nasdaq-100은 100개 기업을 추종하지만 복수 주식 종류 때문에 구성 증권 수는 100개를 넘을 수 있다. 따라서 문서와 화면에는 실제 조회된 구성 증권 수를 표시한다.

### 3-2. 백분위 환산

임의 고정 임계값을 사용하지 않는다. 같은 날 Nasdaq-100 구성종목의 리비전 횡단면에서 지표별 10백분위와 90백분위를 계산한다.

```text
리비전 점수
= clamp((종목 리비전율 - P10) ÷ (P90 - P10) × 100, 0, 100)
```

- P10 이하: 0점
- P10~P90: 선형 환산
- P90 이상: 100점
- P50: 분포 해석과 감사용으로 저장하지만 점수 산식의 절단점으로 쓰지 않는다.
- 지표별 표본이 50개 미만이거나 `P10 ≥ P90`이면 해당 벤치마크를 승인하지 않는다.

다음 네 분포를 서로 섞지 않고 별도로 계산한다.

- 다음 분기 EPS 30일 리비전
- 다음 분기 EPS 90일 리비전
- FY+1 EPS 30일 리비전
- FY+1 EPS 90일 리비전

### 3-3. 2026-08-16 최초 기준값 예시

아래 수치는 고정 임계값이 아니라 최초 생성 결과의 예시다. 운영 시에는 `revision-benchmark.json`의 최신 값을 사용한다.

| 지표 | 표본 | P10·0점 | P50 | P90·100점 |
|---|---:|---:|---:|---:|
| 다음 분기 EPS 30일 | 97 | -2.57% | +0.54% | +16.69% |
| 다음 분기 EPS 90일 | 94 | -3.04% | +1.40% | +19.28% |
| FY+1 EPS 30일 | 99 | -2.22% | +1.02% | +13.23% |
| FY+1 EPS 90일 | 97 | -4.36% | +2.06% | +16.95% |

## 4. 하위 점수

### 4-1. 3개월 전망

```text
3개월
= 다음 분기 EPS 30일 리비전 점수×50%
 + 다음 분기 EPS 90일 리비전 점수×20%
 + FY+1 EPS 30일 리비전 점수×30%
```

### 4-2. 6개월 전망

```text
EPS 성장률 = (FY+1 EPS ÷ FY0 EPS - 1) × 100

6개월
= EPS 성장률 점수×60%
 + FY+1 EPS 90일 리비전 점수×25%
 + FY+1 EPS 30일 리비전 점수×15%
```

EPS 성장률은 -10%를 0점, +60%를 100점으로 선형 환산한다. 이 범위는 EPS 리비전 벤치마크와 다른 성장성 평가 구간이며, 별도 백테스트 전까지 휴리스틱으로 명시한다.

### 4-3. 밸류에이션

```text
Forward P/E = 현재가 ÷ FY+1 EPS
GARP = FY+1 EPS 성장률 ÷ Forward P/E

밸류에이션
= 목표가 상승여력 점수×45%
 + GARP 점수×35%
 + 목표가 30일 리비전 점수×20%
```

현재 환산 구간:

- 목표가 상승여력: -10%→0점, +60%→100점
- GARP: 0→0점, 2 이상→100점
- 목표가 30일 리비전: -5%→0점, +10%→100점

### 4-4. 촉매

```text
촉매
= 다음 분기 EPS 30일 리비전 점수×25%
 + 목표가 30일 리비전 점수×20%
 + γ 상태 점수×25%
 + 사이클 단계 점수×15%
 + FY+1 EPS 상향 비율×15%
```

고정 상태 점수:

| 항목 | 점수 |
|---|---:|
| γ open / flagged / spent | 88 / 55 / 20 |
| 사이클 태동 / 초입 / 가속 / 성숙 / 과열 | 72 / 82 / 92 / 58 / 30 |

EPS 상향 비율은 `상향 수 ÷ (상향 수 + 하향 수) × 100`으로 계산한다.

### 4-5. 컨센서스

```text
컨센서스
= FY+1 EPS 상향 비율×60%
 + 애널리스트 평점 환산점수×40%

애널리스트 평점 환산점수
= 100 - (평균 평점 - 1) ÷ (5 - 1) × 100
```

평균 평점은 1에 가까울수록 긍정적이라는 데이터 제공자 정의를 따른다.

## 5. 리스크 감점

리스크 감점 합계는 최대 20점이다.

| 조건 | 감점 |
|---|---|
| 30일 주가 상승률이 FY+1 EPS 30일 리비전을 10%p 넘게 추월 | 초과 폭에 따라 최대 6점 |
| 다음 분기 EPS 30일 리비전이 음수 | Nasdaq-100 해당 지표 P10 대비 최대 4점 |
| FY+1 EPS 30일 리비전이 음수 | Nasdaq-100 해당 지표 P10 대비 최대 4점 |
| γ spent | 6점 |
| γ flagged 또는 수동 flagged | 3점 |
| 사이클 과열 | 8점 |
| 상승여력 60% 초과이면서 목표가 30일 리비전이 0% 이하 | 괴리와 하향 폭에 따라 최대 7점 |
| FY+1 EPS 하향 애널리스트 수가 상향 수보다 많음 | 하향 우세도에 따라 최대 4점 |

음수 EPS 리비전 감점의 분모도 더 이상 -8%를 사용하지 않는다. 당일 Nasdaq-100 P10의 절댓값을 사용한다.

## 6. 마이크론 계산 예시

2026-08-16 원자료와 당일 Nasdaq-100 기준을 적용한 예시다.

| 항목 | 마이크론 값 | 당일 기준 | 환산점수 |
|---|---:|---:|---:|
| 다음 분기 EPS 30일 | +0.1% | P10 -2.57% / P90 +16.69% | 13.86 |
| 다음 분기 EPS 90일 | +39.7% | P10 -3.04% / P90 +19.28% | 100.00 |
| FY+1 EPS 30일 | +3.7% | P10 -2.22% / P90 +13.23% | 38.32 |
| FY+1 EPS 90일 | +52.1% | P10 -4.36% / P90 +16.95% | 100.00 |

하위 점수는 3개월 38.43, 6개월 90.75, 밸류에이션 84.26, 촉매 54.40, 컨센서스 85.90이다. 리스크 감점은 0점이다.

```text
38.43×30% + 90.75×25% + 84.26×20% + 54.40×15% + 85.90×10%
= 67.82
→ 반올림 68점
```

## 7. 재현성과 감사

- 실제 당일 기준값: `revision-benchmark.json`
- 기준값 생성기: `scripts/fetch-revision-benchmark.mjs`
- 점수 구현 원본: `scripts/apply_zero_base_investment_score.py`
- 사용자 화면 구현: `index.html`의 `ZERO_BASE_INVESTMENT_SCORE_V3`
- 자동 실행: `.github/workflows/update-prices.yml`
- 리비전 원자료: `raw/revisions/`

점수 오류를 조사할 때는 화면 숫자를 역산하지 말고, 같은 기준일의 원자료와 벤치마크 파일을 함께 확인한다.

## 8. 변경 관리 원칙

- 가중치, 환산 구간, 백분위 또는 감점 규칙 변경은 코드·본 문서·운영 매뉴얼을 같은 PR에서 수정한다.
- 실증 근거가 없는 임계값은 임의로 추가하지 않는다.
- 모집단, 제공자 또는 EPS 기간 정의가 바뀌면 기존 점수와 단절될 수 있으므로 변경 전후 영향을 기록한다.
- 기준 생성 실패 시 이전 기준을 조용히 재사용하지 않는다. 워크플로를 실패시키고 원인을 확인한다.
- 점수 변화와 원자료 변화, 모델 변경에 따른 점수 변화를 구분해 변경 이력에 남긴다.
